# Java Programs

This repository contains a collection of Java programs created for learning and practicing Java programming.

## Topics Covered
- Java Basics
- Variables and Data Types
- Operators
- Conditional Statements
- Loops
- Methods
- Arrays
- Strings
- Number Programs
- Pattern Programs
- Object-Oriented Programming (OOP)
- Basic Problem Solving
- DSA Fundamentals

## Purpose
The main purpose of this repository is to strengthen Core Java concepts through hands-on coding practice and improve problem-solving skills.

## Technologies
- Java
- JDK
- VS Code / IntelliJ IDEA / Eclipse

This repository will be updated regularly as I learn and practice new Java concepts.
